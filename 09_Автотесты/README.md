# C#
В папке содержатся автотесты и калькулятор, написанные на C#

## Содержимое
- Калькулятор.txt - Простой консольный калькулятор, написанный на C#
## Возможности
- Сложение
- Вычитание
- Умножение
- Деление
В процессе написание автотестов к калькулятору.

- Selenium-tests - автотесты для корпоративного портала, написанные на C# с использованием Selenium WebDriver.
