## Эта папка содержит примеры баг-репортов, созданных во время тестирования приложений. 
Файлы демонстрируют навыки документирования ошибок.

## Содержимое

- 'bug-001.jpg', 'bug-002.jpg', 'bug-003.jpg' - примеры баг-репортов с [открытого урока](https://open.qa.studio/manual-qa) от QA Studio.
- фидбэк_конструктор_пиццы.jpg - обратная связь от ментора по багам с открытого урока "Конструктор пиццы".
- 'bug-004.jpg', 'bug-005.jpg', 'bug-006.jpg', 'bug-007.jpg' - примеры баг-репортов с учебного курса по тестированию корпоративного портала.
