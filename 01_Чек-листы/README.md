# Чек-листы

В этой папке собраны чек-листы по различным заданиям и проектам.

Каждый файл представляет собой отдельные чек-листы с заданиями внутри. 

## Сожержимое:

- **Чек-лист Заявка** - чек-лист для тестирования редактирования заявки
- **Чек-лист Регистрация** - чек-лист для тестирования формы регистрации
- **Чек-лист РЖД регистрация** - чек-лист для тестирования формы регистрации на сайте РЖД.
- **Чек-лист треугольники** - чек-лист для тестирования утилиты "Треугольники"
