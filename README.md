# Портфолио QA

Привет! Я начинающий тестировщик.

В этом репозитории собраны мои работы: тестовая документация, автотесты, тестирование API, задания по SQL.

- DevTools, Postman, YouTrack, Jira, XMind

- SELENIUM (C#), начальный уровень
