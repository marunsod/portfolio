# API-для пространства KAITEN.

Эта папка содержит коллекцию API-тестов для метода "Создать карточку" в пространстве KAITEN.

## Подготовка:

1. Зарегистрируйтесь в [Kaiten](https://kaiten.ru/).
2. Сгенерируйте API Token в настройках своего аккаунта.


## Файлы:

- KAITEN_API.postman_collection.json - коллекция Postman c запросами на создание карточки.
- KAITEN_postman_environment.json - окружение Postman с переменными.
- KAITEN_создать карточку_кейсы.txt - кейсы для метода "Создать карточку".

## Как использовать

1. Импортируйте коллекцию и окружение в Postman.
2. Запустите коллекцию.

## Переменные окружения:

- base_url - базовый URL API Kaiten.
- token - токен для аутентификации.

 В коллекции реализованы автотесты.
